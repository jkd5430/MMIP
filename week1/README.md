# Quiz 1:彩色影像轉灰階影像
基礎(15%):
• 自行選擇一張彩色影像,將 RGB 彩色影像轉換為灰階影像。

進階(10%):
• 使用 NumPy 自行實作灰階轉換演算法,並與 OpenCV 提供的方法
進行比較。
• 建議重複執行 N 次並取平均值,比較(1)執行速度、(2)轉換結
果、(3)兩種方法之間的差異


(1)執行速度:重複執行100次平均執行速度np速度約0.01秒而CV2速度約0.0002秒
(2)轉換結果:轉換結果差異 第一次實作時將np結果減cv2結果，算整張圖還有多少像素結果為54857130後發現是運算完後轉uint8沒先四捨五入
(3)兩種方法之間的差異:在做這題時有上網查常見的彩色圖片轉灰階的公式 Gray=0.299R+0.587G+0.114B和CV2一樣

# Quiz 2:Histogram Equalization
基礎(15%):
• 自行選擇一張影像,使用 Histogram Equalization 提升影像的明暗對比與動態
範圍。
• 繪製影像在 Histogram Equalization 處理前後的灰階 Histogram,觀察並比較
亮度分布的差異。

進階(10%):
• 使用 NumPy 自行實作演算法,並與 OpenCV 提供的方法進行比較。
• 建議重複執行 N 次並取平均值,比較(1)執行速度、(2)影像增強效果、
(3)兩種方法之間的差異

(1)執行速度:重複100次平均速度自己寫的為0.164秒，CV2為0.0006秒
(2)影像增強效果:直方圖轉換後，原本集中的灰階會分布到更大的範圍，使畫面上有明顯的暗部與亮部。
(3)兩種方法之間的差異 : 用自己寫的跟CV2的相減差值為零，我是按照公式寫的只要沒有出現浮點數或是四捨五入應該都不會有差別，但我寫的比起CV2沒效率很多

# Quiz 3:梯形校正與透視轉換
基礎(15%):
• 選擇一張斜拍影像,利用 Perspective Transformation 將影像校正為
正視影像。
進階(10%):
• 將演算法應用於多張不同拍攝條件的影像,讓同一套流程可以針對多
張影像自動完成梯形校正,自動化程度越高,得分越高。
• 探討不同拍攝角度下的校正效果,找出演算法開始無法正確校正的角
度或條件,並說明可能原因。

我實作了兩個 
第一個是用人工點的，然後就給CV2處理
第二個是要自動化處理 設計流程為 讀取圖片轉灰階 ==> 大津演算法進行二值化 ==> 找最大的連通區塊以及該區塊四個角的座標 ==> 給CV2處理
自動化流程目前發現的問題 我用大津演算法去做因為我假設要用的東西是文件應該都是要白色與背景有很大的差異，所以20260921_171328.jpg這橘色錢包完全失效，以及20260921_171429大鳥大社的影像在二質化後有很多雜訊所以連通區域連背景都進去了，結果較好的是20260921_171137以及IMG_20200204_112217，結果較特殊的是20260921_171137剛好連通區域都有連到左上左下所以才較完整
而我有嘗試在二值化前進行值方圖均衡結果是在大鳥大社的部分影像有效，而在20260921_171137反而把連通區域擴的更大所以反而變差了
